# istok_ui

Biblioteca de componentes React + TypeScript, estilizada com Tailwind CSS 4. Os componentes partem do
[shadcn/ui](https://ui.shadcn.com), com comportamento e acessibilidade do [Radix UI](https://www.radix-ui.com).

## Instalação

O pacote é publicado no npm como `istok-ui`:

```bash
npm install istok-ui
```

## Configuração

No CSS principal do projeto, importe o tema logo depois do Tailwind. É só isso: o tema já faz o Tailwind do projeto
gerar as classes usadas pelos componentes.

```css
@import "tailwindcss";
@import "istok-ui/theme.css";
```

## Tema

Os tokens viram utilitários do Tailwind (`bg-primary`, `text-muted-foreground`, `rounded-lg`…). Veja todos em
**Fundamentos › Tokens**. Para trocar a marca, sobrescreva as variáveis no CSS do projeto:

```css
:root {
  --primary: oklch(0.55 0.2 260);
  --radius: 0.5rem;
}
```

Para o tema escuro, adicione a classe `dark` no `<html>`. Use o seletor de tema na barra do Storybook para ver os
componentes nos dois temas.
